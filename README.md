# Datheon Python Programming Internship

## Task 1: Hangman Game (Console)
A terminal-based Hangman game in Python.

### Features
- Random word selection from a word list (words.txt)
- 6 attempts with ASCII gallows art
- Tracks guessed letters, no penalty for repeated guesses
- Win/loss history saved in a file

### How to run
python hangman.py
